    使い方と撮影のコツ

    かんたんな流れ

    1. ［● 撮影］から画面収録を始める
    2. 地図アプリに切り替えて、縦横にスクロール
    3. 収録を止めて、この画面で取り込む（自動でつながります）
    4. 赤い斜線＝足りない場所。［不足部分を追加撮影］で埋める
    5. ［⬇ 保存］で形（四角／丸）と範囲を選んで1枚の画像に

    撮影の前に

    • 縮尺（拡大率）を決めてから撮影を始める。撮影中は拡大・縮小しない。
    • 地図は北を上に固定（コンパスをタップ）。回転・傾き（3D）はオフ。
    • 現在地の追従をオフに。地図が勝手に動くとずれます。
    • ピンや吹き出し、検索結果の一覧は閉じておく。

    撮影中のコツ

    • 指で画面の1/3くらいずつゆっくりスクロールして、指を離して1秒止める。止まったコマはブレが無く、地図の文字も読み込まれてくっきり取り込めます。
    • はじかない（慣性で流れるスクロールはブレて見失いやすい）。
    • 芝刈りのようにジグザグ：右へ進む → 少し下へ → 左へ戻る → 少し下へ…。行と行は1/3以上重ねる。
    • まんべんなく。赤い斜線が残っても後から追加撮影で埋められます。
    • 海・空白・単色の場所はつながりにくいので、陸地や文字が画面に入るように。

    不足部分を埋める

    • ［不足部分を追加撮影］→ 撮影を始めたらまず取り込み済みの場所を1〜2秒映す（そこで位置を認識）→ 赤い斜線の場所へスクロール。
    • 前回と同じ拡大率で撮影してください。

    画面収録のはじめ方

    • iPhone：アプリの［録画を開始］、またはコントロールセンターの「画面収録」◉。止めるときは画面上部の赤い表示をタップ。（コントロールセンターに無い場合：設定 → コントロールセンター → 画面収録を追加）
    • Android：アプリの［録画を開始］、またはクイック設定（上から2回スワイプ）の「スクリーンレコード」。止めるときは通知から。
    • PC：［撮影］→［ライブ取り込み］でGoogleマップなどのタブを選ぶと、スクロールした範囲がリアルタイムで表示されます。

    取り込む範囲（最初に聞かれます）

    • 検索バー・ボタン・タブバーなど、動かない部分は青い枠の外へ。これが入るとつながりません。
    • 動画の場合は、開始・終了のスライダーで地図以外が映っている部分を外せます。

    保存の形

    • 四角／丸を選べます。
    • 外接：取り込んだ全体が入る大きさ（すき間は白などで埋まる）。
    • 内接：すき間が入らない一番大きな四角／丸。
    • 自由：プレビュー上で枠をドラッグして位置と大きさを決める。

    うまくつながらないとき

    • 赤い点線の画像は位置が分からなかったもの。［✥ 調整］でだいたいの場所へドラッグするとピタッと合います。
    • ずれた画像は［✥ 調整］で選んで［削除］、または［↶ 戻す］。
    • 設定の「位置合わせの厳しさ」を下げると合いやすくなります。
